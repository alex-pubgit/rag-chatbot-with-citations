# ACME token

Sample data: AcmeSwap is a fictional product, used to demonstrate this chatbot.

## Where ACME exists

The ACME token exists on BNB Smart Chain only. Tokens named ACME on any other network are not issued by AcmeSwap.

## Contract address

The official ACME contract address is published only on the official website. This help center does not list it, so that a copied or edited page cannot point you to a fake token. Always compare the address in your wallet with the one on the official website before you trade.
