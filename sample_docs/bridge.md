# Bridge

Sample data: AcmeSwap is a fictional product, used to demonstrate this chatbot.

## Moving tokens between networks

The bridge moves tokens between the supported networks. A bridge transfer usually takes 5 to 20 minutes, depending on how busy both networks are.

## Bridge fee

The bridge fee is 0.05% of the amount, with a minimum fee of 1 USDT equivalent. You also pay the network fee on the network you send from.

## Delayed transfers

If a bridge transfer is still pending after 60 minutes, report it to support and include the transaction hash. Do not send the transfer again while the first one is pending.
